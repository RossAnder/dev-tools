## Deviations

- Health rule, which the detail left open. `health()` lists a probeable accept whose verdict is not `healthy`, a probeable premise whose verdict is not `holds`, and a gate probe whose verdict is not `holds`. An unrecorded probe counts and shows `verdict = ""`. Entries the emitter would skip (`probeable = false`) are left out. The alternative, flagging only recorded bad verdicts, would hide probes that are due but never ran.
- The parked task is existing task 8 with its status changed, not a new ninth task. A ninth task changes the task count and layer-0 width, which would break header, subset and diagram layout tests in files this task does not hold; parking task 8 leaves topology unchanged and broke only the three view assertions fixed above.
